## 🌍 全局快捷键

### 核心操作

| 按键 | 功能 | 说明 |
|------|------|------|
| `?` | 帮助 | 显示/隐藏帮助面板 |
| `q` | 退出 | 退出应用（有未保存内容时会提示） |
| `Ctrl+C` | 强制退出 | 立即退出，不保存 |

### 快速操作

| 按键 | 功能 | 说明 |
|------|------|------|
| `Ctrl+N` | 快速请求 | 打开快速输入框，直接输入 URL 发送请求 |
| `Ctrl+T` | 新建文件 | 创建新的 .http 测试文件 |
| `Ctrl+O` | 打开文件 | 打开文件选择器 |
| `Ctrl+E` | 编辑当前 | 在内置编辑器中编辑当前请求 |
| `Ctrl+S` | 保存 | 保存当前编辑（编辑器模式） |
| `Ctrl+R` | 运行请求 | 发送当前请求 |
| `Ctrl+Enter` | 快速发送 | 发送请求（任意面板） |

### 导航

| 按键 | 功能 | 说明 |
|------|------|------|
| `Tab` | 切换面板 | 在请求、响应、文件树间顺序切换 |
| `Shift+Tab` | 反向切换 | 反向切换面板 |
| `Ctrl+1` | 请求面板 | 直接跳到请求编辑面板 |
| `Ctrl+2` | 响应面板 | 直接跳到响应查看面板 |
| `Ctrl+3` | 文件面板 | 直接跳到文件树面板 |
| `Ctrl+H` | 历史记录 | 打开历史记录面板 |

### 搜索与过滤

| 按键 | 功能 | 说明 |
|------|------|------|
| `/` | 搜索 | 在当前面板中搜索 |
| `n` | 下一个 | 跳到下一个搜索结果 |
| `N` | 上一个 | 跳到上一个搜索结果 |
| `Esc` | 清除搜索 | 退出搜索模式 |

## 💡 提示与技巧

### 快速工作流示例

1. **快速测试 API**
   ```
   Ctrl+N → 输入 URL → Enter
   ```

2. **创建测试文件**
   ```
   Ctrl+T → 输入文件名 → 选择模板 → Enter
   ```

3. **编辑并运行**
   ```
   Ctrl+E → 编辑请求 → Ctrl+Enter
   ```

4. **从历史重现**
   ```
   Ctrl+H → 选择记录 → r（重新运行）
   ```

### 组合键技巧

- `Ctrl+N` + `Ctrl+V`：粘贴 curl 命令后直接发送
- `Ctrl+H` + `s`：将历史请求保存为测试文件
- `Tab` + `/`：在任意面板快速搜索
- `?` + `q`：查看帮助后快速退出

## 🎨 可自定义快捷键

在 `~/.rupost/keybindings.toml` 中自定义：

```toml
[global]
quit = "q"
help = "?"
quick_request = "Ctrl+n"

[file_tree]
new_file = "a"
delete = "d"
rename = "r"

[editor]
save = "Ctrl+s"
run = "Ctrl+Enter"
```
